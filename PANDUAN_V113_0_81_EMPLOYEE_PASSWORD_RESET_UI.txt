HappyLaundry V113.0.81 — Employee Password Reset UI

Cara ganti password karyawan:
1. Login sebagai Owner.
2. Buka Pengaturan > Kelola Karyawan.
3. Pada baris karyawan, klik tombol Reset Password.
4. Isi Password Baru dan Konfirmasi (minimal 8 karakter), atau klik Generate Password Baru.
5. Klik Reset Password.

Tidak perlu SQL baru. Backend menggunakan fungsi reset password yang sudah ada.
