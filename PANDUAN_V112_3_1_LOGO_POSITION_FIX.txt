HAPPYLAUNDRY ENTERPRISE V112.3.1 — LOGO POSITION FIX

MASALAH V112.3:
Pilihan posisi Kiri / Tengah / Kanan dapat terlihat tidak berubah atau hasil cetak tetap berada pada posisi lama.

PENYEBAB:
Posisi sebelumnya terutama mengandalkan flex alignment.
Pada kombinasi CSS/template tertentu, aturan layout lain dapat mengalahkan posisi logo.

PERBAIKAN V112.3.1:
Logo sekarang menggunakan DUA lapisan posisi:
1. text-align pada pembungkus
2. margin-left / margin-right langsung pada gambar

KIRI:
margin-left: 0
margin-right: auto

TENGAH:
margin-left: auto
margin-right: auto

KANAN:
margin-left: auto
margin-right: 0

Selain itu inline style ikut ditulis langsung ke HTML nota sehingga aturan CSS lain tidak dapat memindahkan posisi logo.
