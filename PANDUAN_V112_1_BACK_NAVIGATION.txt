HAPPYLAUNDRY ENTERPRISE V112.1 — TOMBOL KEMBALI / ARROW BACK

PERUBAHAN:
Semua halaman utama sekarang mempunyai tombol:
← Kembali

Dashboard utama tidak menampilkan tombol kembali.

CONTOH:
Dashboard -> Order
Di halaman Order tersedia:
← Kembali

Klik akan kembali ke Dashboard.

Dashboard -> Pengaturan -> Pengaturan Absensi
Di Pengaturan Absensi tersedia:
← Kembali

Jika dibuka dari Pengaturan, tombol kembali akan kembali ke Pengaturan.

dan halaman lain yang menggunakan PageHeader.

CARA KERJA:
Jika ada riwayat halaman di aplikasi:
tombol menggunakan browser back.

Jika halaman dibuka langsung / refresh:
sistem menggunakan fallback aman:
- subhalaman Pengaturan -> Pengaturan
- subhalaman Keuangan -> Keuangan
- halaman utama lain -> Dashboard

HP / IPHONE:
Tombol tampil sebagai icon panah besar 42x42 px agar mudah ditekan.
Saat area header bergerak, tombol dibuat sticky di layar kecil.

DESKTOP:
Tombol menampilkan:
← Kembali
