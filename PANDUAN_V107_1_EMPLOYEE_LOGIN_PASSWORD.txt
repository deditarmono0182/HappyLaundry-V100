HAPPYLAUNDRY ENTERPRISE V107.1 — EMPLOYEE LOGIN PASSWORD

FITUR BARU:
- Owner mengisi password langsung saat Tambah Karyawan.
- Generate Password otomatis.
- Show / Hide Password.
- Konfirmasi Password.
- Akun Supabase Authentication dibuat otomatis.
- Reset Password dari aplikasi.
- Copy informasi login.
- Kirim email + password sementara ke WhatsApp karyawan.
- Password TIDAK disimpan di tabel HappyLaundry.

HAK AKSES TETAP:
Dashboard
Kasir
Order
QR Center
Produksi
Pelanggan
Layanan

PENTING — EDGE FUNCTION:
Fitur membuat/reset password menggunakan:
supabase/functions/employee-admin/index.ts

SERVICE ROLE KEY hanya dipakai DI SERVER Supabase Edge Function.
JANGAN pernah memasukkan Service Role Key ke .env frontend, GitHub, atau Netlify browser variables.

LANGKAH INSTALASI:

A. SQL
1. SQL 009 dari V107.0 harus sudah dijalankan.
2. Jalankan:
   supabase/010_v107_1_employee_login_support.sql
   (SQL ini ringan dan tidak menyimpan password.)

B. DEPLOY EDGE FUNCTION
Cara termudah dengan Supabase CLI:

1. Login:
   supabase login

2. Link project:
   supabase link --project-ref PROJECT_REF_ANDA

3. Deploy:
   supabase functions deploy employee-admin

Supabase menyediakan environment variables berikut untuk function:
SUPABASE_URL
SUPABASE_ANON_KEY
SUPABASE_SERVICE_ROLE_KEY

C. DEPLOY APLIKASI
1. Copy project ke HappyLaundry-V100.
2. Replace.
3. Commit:
   HappyLaundry V107.1 Employee Login Password
4. Push origin.
5. Tunggu Netlify Published.
6. Ctrl + Shift + R.

CARA PAKAI:
1. Pengaturan -> Karyawan & Hak Akses.
2. Tambah Karyawan.
3. Isi Nama, Email, WhatsApp.
4. Isi password atau klik Generate Password.
5. Pilih hak akses.
6. Klik Buat Akun Karyawan.
7. Akun langsung dibuat di Supabase Authentication.
8. Klik Kirim WhatsApp untuk mengirim informasi login.

RESET PASSWORD:
1. Di daftar karyawan klik ikon Reset Password.
2. Generate atau isi password baru.
3. Klik Reset Password.
4. Kirim password baru ke karyawan.

CATATAN:
- Password minimal 8 karakter.
- Email login karyawan tidak dapat diubah lewat Edit; buat akun baru jika email harus diganti.
- Menonaktifkan karyawan di HappyLaundry menutup hak akses menu aplikasi.
